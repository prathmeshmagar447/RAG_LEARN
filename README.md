# RAG-LEARN

This repository contains various examples and implementations related to Retrieval Augmented Generation (RAG) for beginners. It covers different aspects of RAG, including ingestion pipelines, retrieval methods, answer generation, and more.

## Contents

- `1_ingestion_pipeline.py`: Script for setting up the data ingestion pipeline.
- `2_retrieval_pipeline.py`: Script for defining the retrieval pipeline.
- `3_answer_generation.py`: Script for generating answers based on retrieved context.
- `4_history_aware_generation.py`: Script for generation with conversational history.
- `5_recursive_character_text_spliiter.py`: Example of recursive character text splitting.
- `6_semantic_chunking.py`: Example of semantic chunking.
- `7_agentic_chunking.py`: Example of agentic chunking.
- `8_multi_modal_rag.ipynb`: Jupyter notebook demonstrating multi-modal RAG.
- `9_retrieval_methods.py`: Various retrieval methods implementations.
- `10_multi_query_retrieval.py`: Example of multi-query retrieval.
- `11_reciprocal_rank_fusion.py`: Implementation of reciprocal rank fusion.
- `12_hybrid_search.ipynb`: Jupyter notebook demonstrating hybrid search.
- `13_reranker.ipynb`: Jupyter notebook demonstrating reranking.
- `requirements.txt`: Python dependencies for the project.
- `docs/`: Directory containing documentation files.

## Setup

1. Clone the repository:
   ```bash
   git clone [YOUR_REPOSITORY_URL]
   cd RAG-LEARN
   ```
2. Create a virtual environment and install dependencies:
   ```bash
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
